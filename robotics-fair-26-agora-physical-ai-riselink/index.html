Weather MCP, free to test.

The server runs locally over stdio and uses free public weather data. A voice agent can request a forecast or active alerts, then speak the result.

Free public data No API key currently Local stdio
MCP transport stdio: node .../weather/build/index.js

Runs as a local process; there is no hosted MCP URL or service fee.

Weather data endpoint https://api.weather.gov

Free NWS open data. A User-Agent and reasonable rate limits apply. NWS policy

get_forecast

Returns a weather forecast for a latitude and longitude.

get_alerts

Returns active weather alerts for a US state code.

AI-ready terminal command

Flash the R1 with bk_loader.

Update the serial port and firmware image path, then run this command from your terminal.

bk_loader download \
  --portnum /dev/cu.wchusbserial110 \
  --baudrate 115200 \
  --infile /path/to/beken_r1_all-app_sg3.bin \
  --startaddr 0x0 \
  --pre_erase 1 \
  --reboot
Replace example paths before running
