AI-ready terminal command

Flash ReSpeaker with esptool.

Update the serial port and firmware image path, then run this command from your terminal.

esptool \
  -p /dev/cu.wchusbserial1320 \
  -b 460800 \
  write_flash --erase-all \
  0x0 /path/to/respeaker-flex-agora-mybot.bin
Replace example paths before running
Optional audio interface update

Switch XVF3800 to I2S mode.

The XIAO ESP32-S3 exchanges voice data with the XVF3800 over I2S. This update changes the microphone array from its factory USB mode to the I2S mode used by this workshop.

Flash it when audio is noise Use this image if the device produces loud static or noise instead of clear microphone audio, or if the XVF3800 is still running its factory USB firmware.
Skip it when audio is clean This is not the Agora application firmware. If your ReSpeaker already captures clean audio over I2S, leave the XVF3800 firmware unchanged.
Connect the XMOS portUse the USB-C port near the RST button, not the XIAO USB-C port.
Install DFU UtilWindows: download 0.11, extract win64, and add it to Path.
macOS: brew install dfu-util
Linux: sudo apt install dfu-util
Check the deviceRun dfu-util -l. If it is missing, hold Boot while reconnecting power to enter Safe Mode. On Windows, install the WinUSB driver with Zadig if access fails.
Download and flashDownload the I2S image, update the path in the command, and wait for the board to restart.
dfu-util -R -e -a 1 -D /path/to/respeaker_flex_i2s_c16k2ch_v1.0.0.bin
